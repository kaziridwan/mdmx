# mdmx 0.6.0

The first npm release of mdmx (`@mdmx/*`, MIT). Three themes: the demo app
is a real Tailwind v4 + shadcn app, the entry editor renders truthfully, and
the packages ship.

## The canvas is the page

- The editor puts your **content class** on its canvas root (`mdmx-page` by
  convention, `contentClassName` to change it), so your site's typography,
  colors, and component styles apply while editing — measured
  element-by-element against the public page: identical.
- **`fit` is the default preview** (real size, zoom 1); mobile/tablet/desktop
  are framed device previews. The component rail and the sidebar **collapse**
  from the toolbar.
- **Components are live**: buttons, inputs, tabs, and accordions work inside
  the editor; clicking anything else selects the block; links never navigate
  (⌘-click opens a tab). Override per component with `render: { interactive:
  true | false }` (registry schema v2).
- `@mdmx/editor` now ships its chrome as `@mdmx/editor/styles.css`; the
  dashboard's stylesheet renders the same under Tailwind's preflight, another
  reset, or no global CSS.

## shadcn, first-class

- `examples/demo-next` runs Next 16 (Turbopack), Tailwind v4, and the full
  shadcn set; **22 shadcn components are registered as blocks** and the 17
  marketing components are rebuilt on shadcn primitives with their props
  unchanged. ADR-053 records the rules for what can be a block.
- Studio components in a Tailwind app compile through **your** Tailwind build
  from a generated class manifest (`.mdmx/studio-classes.txt` + one `@source`
  line); the CDN runtime is gone from those apps, and `mdmx check` tells you
  if the line is missing.

## Distribution

- MIT license; all eight packages publish under `@mdmx`.
- `pnpm pack:all` + `pnpm.overrides`: use mdmx from a checkout between
  releases (guide 08).

## Compatibility

- Peers stay `next >=15`, `react >=18`; the demo runs Next 16.3 / React 19.2.
- Registry schema v2 (`render.interactive`); v1 registries read unchanged.
  Run `mdmx generate` once.
- Content format unchanged: canonical MDMX round-trips byte-for-byte.
